Slide 02 / 10 • Context & Motivation

The Problem: Academic Information Chaos

Why traditional student management systems fail college students during crucial exam periods

Real Student Pain Points
  • Fragmented Schedules: Exam timetables arrive in PDF circulars, assignments in chat channels, and grades in disjointed portals.
  • Preventable Deadlines Missed: Students lose track of submission cut-offs amid concurrent project milestones.
  • Unchecked Schedule Clashes: Overlapping exam time slots go unnoticed until attendance day.
  • Reactive Cramming: Students realize which subjects are below passing threshold only after finals begin.
The Failure of Conventional Tools

Conventional college applications are passive databases: they allow administrators to record rows, but do nothing to guide student behavior.

Static to-do lists fail because they lack academic context—they cannot evaluate how an upcoming exam in a 48% average subject is far more critical than a homework task in a 90% subject.

Slide 05 / 10 • Core Module 2

Smart Academic Planner & Study Scheduler

Multi-factor priority ranking and greedy knapsack-style study session planning

Transparent Priority Scoring Formula
Task Score = Urgency_Score + Priority_Weight + Subject_Vulnerability + Effort_Factor

• Urgency: Overdue (> 100 pts) • < 24h (90-75 pts) • < 48h (75-60 pts) • > 7 days (baseline)
• Priority: Critical (40 pts), High (30 pts), Medium (20 pts), Low (10 pts)
• Subject Vulnerability: Boost of up to +35 pts if student average in that subject is below the threshold (< 60%)
• Effort Factor: Quick-win boost (+15 pts) for deliverables requiring 1 to 3 hours

Suggested Daily Study Scheduler

Students input available study hours (e.g. 3.5h). The engine greedily allocates the highest-ranked pending tasks fitting within that time budget, eliminating decision paralysis.

Slide 06 / 10 • Core Module 3

Examination Management & Collision Engine

Interval overlap detection and FIFO Academic Service Request Queue

Algorithmic Conflict Detection

Performs pairwise interval checking for all scheduled examinations sharing an identical date.

Overlap Condition:
max(start_1, start_2) < min(end_1, end_2)

If true, the system flags an immediate schedule clash with exact colliding duration, venue, and subjects.

FIFO Academic Request Queue (CO1)

Demonstrates First-Come, First-Served processing for administrative student requests (Hall ticket generation, grade re-evaluation, supplementary exams).

  • Engineered using linked nodes with front and rear pointers.
  • Strict O(1) enqueue and dequeue operations without array shifting.
  • Visual track from FRONT (Exit) to REAR (Entry).
Slide 07 / 10 • Core Module 4

Academic Performance Analyzer

Explainable decline detection and reverse target score calculation

Explainable Decline Detection

Evaluates chronological marks across quizzes, tests, and mid-terms per subject.

  • Sudden Drop: Flags warning if the latest score drops by ≥ 10% compared to previous assessment.
  • Negative Trajectory: Flags warning if 3 consecutive assessments exhibit a downward trend.
  • Prevents surprises before final university grading.
Reverse Target Score Calculator

Given existing weighted marks, determines the exact score needed on an upcoming exam to achieve a target average.

Score_Req = [Target * W_total - Current_Weighted_Pts] / W_upcoming

Validates mathematical feasibility: alerts student if target is already secured or if it exceeds the maximum possible 100% ceiling.

Slide 08 / 10 • Flagship Innovation

Flagship: Academic Rescue Mode

An automated emergency triage engine designed for high-stress finals periods

Academic Crisis Index (0 to 100)

Synthesizes emergency risk metrics: overdue count, tasks due in < 48 hours, subjects below threshold (< 60%), and exams within 10 days.

Severe Pressure (≥ 70) Moderate Warning (≥ 40) Stable (< 40)
Emergency Triage Scoring Formula
Rescue Score = Urgency * 0.45 + Vulnerability * 0.35 + Priority * 0.15 + QuickWin * 0.05

Heavily penalizes overdue tasks and subjects at risk of failing, while providing a slight boost to low-effort quick wins.

One-Click Resolution with Real-Time Recalculation

Students click "Mark Completed & Recalculate" on recommendation #1. The engine instantly recalculates all task scores and re-ranks remaining tasks in real time without a page refresh.
